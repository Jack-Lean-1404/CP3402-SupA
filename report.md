# Project Report

## Project Overview

In this project, I developed and deployed a custom WordPress website for U3A Townsville using modern web development tools and workflows. I created and customised a WordPress child theme to safely extend the parent theme while maintaining compatibility with future updates. The project focused on building a responsive, maintainable, and professional website using industry-standard practices.

I developed the website locally using Docker and Docker Compose, which allowed me to work within a containerised development environment. I also deployed the production website to an AWS EC2 server, giving me practical experience with cloud hosting and Linux server management.

## Technologies and Tools Used

Throughout the project, I used WordPress, PHP, HTML, and CSS to build and customise the website. I used Docker and Docker Compose to manage the local development environment and MariaDB database containers. For version control and collaboration, I used Git and GitHub to manage project changes and development workflows.

To deploy the live website, I used AWS EC2 and connected to the server using SSH. This allowed me to gain experience working with cloud infrastructure and remote deployment processes.

## Skills Developed

This project improved my skills in WordPress theme development, frontend web development, and responsive design. I learned how to create and manage child themes, customise website layouts, and maintain a clean and organised project structure.

I also gained practical experience using Docker for containerised development and AWS EC2 for production hosting. In addition, I strengthened my understanding of Git-based version control, technical documentation, and collaborative development workflows.

## Project Outcomes

Overall, this project gave me valuable real-world experience with modern web development practices and tools. I developed technical skills in WordPress development, cloud deployment, Docker environments, and source control while also improving my problem-solving and documentation abilities.

The experience gained through this project has strengthened my readiness for future roles in web development and software engineering.
